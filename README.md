# SPARK

SPARK is a school-friendly gaming portal in progress. The goal is to make a fun, polished home for a curated arcade, useful guides, and a school information hub.

## Current build

- Responsive dark charcoal and acid-lime visual identity
- SPARK logo artwork from the project owner's original design
- Homepage sections for the arcade, guides, and school hub
- Search and category filters for the placeholder arcade cards
- Mobile navigation and reduced-motion support
- No accounts, trackers, or external game embeds in this first homepage foundation

## Project files

- `index.html` — page structure and content
- `style.css` — colors, layout, animation, and responsive styling
- `script.js` — mobile navigation, arcade search/filter, and date display

## Important

The arcade cards are currently design placeholders, not playable games. Add games only after checking that they are appropriate, reliable, permitted to embed, and usable on school Chromebooks.

SPARK is a working project name.
